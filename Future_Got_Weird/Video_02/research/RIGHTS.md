# Rights register: candidate assets for Video 02

Compiled 2026-10-08. This is a practical register built from what we could establish. It is not legal advice; where
the terms are unknown, it says so. "May we show it?" uses four answers:

- **Yes**: established terms allow it, or the asset is our own work.
- **Yes, with caveat**: probably fine, but a stated gap remains.
- **No, reference only**: keep it for checking facts.
- **Only with permission**: show it only after written permission arrives.

(`direct`). MIT covers "this software and associated documentation files". The repo has **no separate data licence**,
so whether MIT covers the captured `.npz`/`.npy` data is **ambiguous**.

- The paper's Data availability statement says the code and data are "publicly available" at this repo

**Recommended:** credit the authors, link the repo, state "plotted by us". As a courtesy, email the authors before
publication. This is optional, but it cheaply removes the ambiguity.

   and scope in `package/` once it arrives.
