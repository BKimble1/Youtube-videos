# Reference study for the pass-2 look (what was and was not accessible)

Date: 7 October 2026, from the production container.

**Access limits, stated plainly.** The container's network policy blocked youtube.com, i.ytimg.com,
thoughtcafe.ca and remotion.dev (HTTP CONNECT 403). None of the five reference videos was watched, no frame
was analysed, and the Thought Café portfolio page was not opened. What follows combines (a) the principles the
brief itself attributes to each reference, (b) the earlier project's `research/reference_study.md`, which
was built from 3Blue1Brown's published captions and lesson pages, and (c) general craft knowledge of cutout
animation. No creator's artwork, characters, logos, music or footage was used or imitated.

| Reference | Principle applied in Video 01 pass 2 | Where it shows |
|---|---|---|
| Crash Course World History #1 (Thought Café cutout sequences) | Expressive characters with concrete props, staged action that carries the narration, a visual joke with a reaction beat, composition changes instead of slides | The answer counter (clerks hand slips, the fact-checker stamps), the library (the clerk assembles a title-shaped slip from shelf words), the game show (trophy walks back) |
| Thought Café portfolio description (consistent brand, colour and type system, stylised references, segment types, accurate illustration) | A fixed palette, a four-face type system, recurring segment types (evidence pin-up, stamp verdict, chip labels), real documents drawn as pinned evidence | `STYLE_GUIDE.md`, `Evidence.tsx`, the chip wording |
| Kurzgesagt, "A.I. — Humanity's Final Invention?" | Full illustrated environments with depth, large colour fields, continuity of a world across scenes, clarity at small sizes | Three-plane sets with parallax, the apparatus room reused for "what helps", chips checked at phone size |
| Vox, "AI art, explained" | Real imagery used as evidence inside an argument: establish, then isolate the relevant detail | Table 1 excerpts on slips, the paper header cut-in, the thesis title page with sequential highlights, Table 2 column sweeps |
| 3Blue1Brown, "Transformers, the tech behind LLMs" | One visual object carried through the explanation; one relationship at a time; the same chart returns when the idea returns | The ChatGPT slip is the carried object (counter → apparatus → library → record → verification → payoff); the scorer teaches likelihood first and "truth is not measured" second; the dark lecture look is deliberately not imported |

Decisions recorded for later episodes:

1. Every explanation gets a carried object (here: the slip). Introduce it in the hook; stamp it at the end.
2. Characters act before text explains. Text names, it does not narrate.
3. Evidence is pinned, not floated: tape, a card, a chip with the source, one highlight at a time.
4. One joke per act at most, then back to the explanation.
5. A reference's principles are borrowed; its identity is not.
