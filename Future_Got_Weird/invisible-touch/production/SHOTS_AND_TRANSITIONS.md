# Invisible Touch V1: shots, timing and transitions

The film is 934 frames at 30 fps, 31.133 s. Every time below is measured on the narration master. Beats are keyed to
the word onsets in `source/src/it/timing.ts`, not to fixed boundaries.

There are 25 compositions in three settings (lab, car, lobby) and three illustration modes (real scene, macro,
cutaway). No composition is held static for more than 7 frames.

## Transition list

Each line reads: outgoing → incoming → new information → keep, merge or remove.

1. **ECU fingertip → arc → medium** (one continuous move) → empty air round the finger, then the array beneath it →
   **keep**.
2. **Medium → low angle through the gap** (cut) → the separation, proved with a card passing through → **keep**.
3. **Low angle → close on the finger** (cut, the other side) → the question, posed on the finger → **keep**.
4. **Finger → illustrative macro** (match cut, the same fingertip on screen) → the start of the explanation →
   **keep**.
5. **Macro → array** (dive) → the transducers under the hand → **keep**. One connected move from here to the
   cutaway: array → side section → crest → fingertip → receptors.
6. **Array → side cross-section** (swing) → the delayed firing and the converging crests → **keep**.
7. **Section → fingertip** (ride the crest up) → where the waves meet → **keep**.
8. **Fingertip → receptors** (a local cutaway in place, no cut) → why skin feels it → **keep**.
9. **Macro → open hand** (pull-back) → a moving spot → **keep**.
10. **Open hand → low under-palm view** (camera move) → the circle traced → **keep**.
11. **Overlay view → plain hand** (cut) → the clarity beat: nothing is there → **keep**.
12. **Plain hand → medium press on nothing** (cut) → no button → **keep**.
13. **Lab hand → car hand** (match cut on pose, scale, place and motion) → a new place, the car concept →
    **keep**.
14. **Car fingertip → lobby fingertip** (match cut) → a new place, the floating button → **keep**.
15. **Lobby → lab** (cut) → back to the real device for the weird part → **keep**.
16. **Hand → face → hand** (tilt) → the reaction, then touch, not impact → **keep**.
17. **Hand → opening ECU** (one move) → the loop → **keep**.

Nothing was removed. No transition returns to a previous subject without completing an explanation. The only
there-and-back is the tilt to the face and back, which adds the reaction.
