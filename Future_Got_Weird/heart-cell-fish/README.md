# Future Got Weird: The Fish Made From Human Heart Cells

## V1 (review cut)

**Deliverable:** `exports/FGW_HEARTFISH_V1_REVIEW_1080x1920.mp4`. Not published.

- **Video:** H.264, 1080 × 1920, 60 fps, 1802 frames, 30.03 s, CRF 16, yuv420p, BT.709. Captions burned in.
- **Audio:** AAC 48 kHz stereo, 320 kb/s target. Narration, effects, ambience and a restrained music bed.
- **Loop:** the last frame returns to frame 0 (the same camera, fish pose and swim phase).

**Where to look:**

- **Report:** `production/V1_REPORT.md` (what was built, measurements, QA, known limits).
- **Shots and transitions:** `production/SHOTS_AND_TRANSITIONS.md`.
- **Science, sources and simplifications:** `production/SCIENCE_NOTES.md`.
- **Narration (verbatim):** `production/NARRATION_LOCKED.txt`.
- **Voice and alignment:** `audio/narration/voice_provenance.json`, `audio/narration/whisperx.json`.
- **QA evidence:** `qa/`.

## Narration

- **Voice:** the channel narrator, ElevenLabs "Test Voice" `kk5XaSLo2XAw0sKM98zU`, `eleven_v4`, inline direction tags
  only. One run of two takes; take 1 used sample for sample.
- **Sync:** WhisperX. Each take was transcribed (faster-whisper small.en) and checked against the locked words (both
  WER 0). The locked words were then force-aligned to take 1 with wav2vec2 (`facebook/wav2vec2-base-960h`). Every
  caption, shot boundary and sound cue is keyed to those word times at 60 fps.

## Picture

Remotion 4.0.533 (React 19, TypeScript), deterministic SVG in the Future Got Weird vector finish: flat cel colour, one
soft gradient per surface, light from the upper left, navy ink of constant screen width.

| Module | What it draws |
|---|---|
| `source/src/fish/model.ts`, `Fish.tsx`, `swim.ts` | The biohybrid fish as one 3D model after the 2022 prototype. Paper front and tail, a gelatin hinge, a cardiomyocyte sheet on each face, the G-node, the floater fin. It bends only at the hinge, swims by the antagonistic cycle and is drawn through any camera (side, overhead, X-ray). |
| `source/src/core/cam.ts` | The 3D camera (the FGW 3D layer with a free up-vector for the overhead view). |

| `source/src/art/cells.tsx` | Cardiomyocytes under the microscope, beating together. |
| `source/src/art/heart.tsx` | The human heart: a painted model and the living, beating organ, from one drawing. |
| `source/src/lab/` | The lab set (wall, window, clock, bench, glass tank, heart model). The scientist is the crew's guesser in his lab outfit, on the Death Clock / Real Web Fluid rig (`source/src/dc/`, unchanged). |

## Rebuild

    python3 -m pip install whisperx soundfile scipy pyloudnorm    # torch comes with whisperx
    python3 tools/make_narration.py                                # WhisperX check + alignment -> timeline.json, SRT, master wav
    source/node_modules/.bin/esbuild tools/export_cues.ts --bundle --platform=node --format=cjs --jsx=automatic --outfile=/tmp/ec.cjs && node /tmp/ec.cjs audio/cues.json
    python3 tools/make_audio.py                                    # writes source/public/audio/mix.wav
    (cd source && npm ci && npx remotion render src/index.ts HeartFishV1 ../exports/FGW_HEARTFISH_V1_REVIEW_1080x1920.mp4 \
      --props='{"audio":"mix","captions":true}' --crf=16 --x264-preset=slow --pixel-format=yuv420p --color-space=bt709 \
      --audio-codec=aac --audio-bitrate=320k --concurrency=4)
    python3 tools/qa.py exports/FGW_HEARTFISH_V1_REVIEW_1080x1920.mp4 qa

**Model downloads.** WhisperX needs Hugging Face (`huggingface.co` and its CDN hosts) in the environment's network
allowlist. In this environment the NLTK sentence data could not be fetched, so `make_narration.py` passes each sentence
as its own segment.

**Contact sheets:** `cd source && node stills.mjs out.png "f1,f2,..." [cols] [comp] [captions] [scale]`. Each frame is
rendered as its own still, so per-frame SVG ids never collide.

Media are stored as plain git blobs (the episode `.gitattributes` turns LFS off, as in the other FGW episodes).
`source/public/audio/*.wav` and `audio/mix/stems/` are regenerated by `make_audio.py` and are not committed.
