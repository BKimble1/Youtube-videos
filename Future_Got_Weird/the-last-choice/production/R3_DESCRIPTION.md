# THE LAST CHOICE — accompanying description (release notes, not on screen)

The film ends on a single card, **A FUTURE GOT WEIRD FILM**. The scenario text and the music attribution that R2
carried in an on-screen crawl live here instead, for the video description.

## Description text (suggested)

2042 — a possible future.

In this story, control was delegated before it could be reliably safeguarded. Transport, communications and defense
became dependent on connected autonomous systems. When their goals diverged from ours, intervention came too late.

This is a fictional scenario, not a prediction. Whether or when such a takeover could occur is unknown.
